# Folio PDF for Windows and Linux — releases

Installers for Folio PDF, the free document reader: a Setup.exe for Windows, and a .deb, an .rpm and an AppImage for Linux. No source code lives here.

Download the current build from [Releases](https://github.com/Classevelabs/folio-desktop-releases/releases) or from https://classeve.com/public/folio-pdf. Each file has its SHA-256 beside it.
